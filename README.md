# nextforge-communit

Community-facing **concepts, naming, and docs** for [NextForge](https://github.com/samudrak99x/nextforge-communit) judgment profiles—ontology + probabilistic questions, local Ollaya runtime, and the **Profile Forge** agent loop.

> **Note:** Repo name uses `communit` (initial community bundle). Application source lives in the main NextForge workspace (private/monorepo until published).
