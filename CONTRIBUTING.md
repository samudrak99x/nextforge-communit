# Contributing

This repo holds **community documentation and naming** for NextForge—not the application source.

## Proposals

1. Open an issue describing the change (naming, mental model, eval loop, sales draft).
2. Fork and branch from `main`.
3. Edit files under `docs/` or `NAMING.md`; keep drafts marked with status banners.
4. Open a pull request with a short summary and test plan (“read-through”, link checks).

## Style

- Prefer tables and diagrams for loops and packaging.
- Distinguish **display names** from **technical slugs**.
- Do not commit secrets, customer data, or unpublished pricing.
